# Research screenshots

Captured from actual public sites on 7 October 2026. These are reference evidence, not release-quality marketing assets or complete gameplay verification.

- `burnhop-live.png`: https://burnhop.lowhp.studio/ entrance with pilot, moonlit desert, title, and Enter game control. Collaborative-browser capture at 1280 x 800.
- `templio-live.png`: https://www.templio.app/ custom-websites homepage, with the live rotating showcase displaying Bikramdeep Singh's portfolio. Collaborative-browser capture at 1280 x 800. Do not represent that person as Low HP's founder or as an additional Low HP product.
- `greytrace-live.png`: https://www.greytrace.lowhp.studio/ lobby with Play, Collection, Updates, Range, and TDM controls. Headless Chromium capture at 1280 x 800 after waiting for a visible button. Used the shell browser only after the collaborative browser reported its automation host unavailable. Shooting, pointer lock, audio, and multiplayer were not tested.

The original HTML direction study uses only the Burnhop screenshot. That concept was superseded by the Awwwards-inspired implementation.

`burnhop-sharp.png` and `templio-sharp.png` are fresh 1600 × 1000 local Chromium captures of the same public sites after fonts loaded, with reduced motion enabled. These supply the final optimized WebP assets. Greytrace uses the existing real lobby capture. `public/studio/ayush.webp` derives from the founder’s existing illustrated portrait on his personal portfolio. None of these are invented project interfaces.
